1. Maximum accuracy and code

The submitted test accuracy is 85.00% (340 of 400). The encoder is frozen SigLIP SO400M, google/siglip-so400m-patch14-384. Its class weights are the averaged text prompts for the 16 scene names. Each test image is embedded together with its horizontal flip, and the two vectors are averaged before the cosine comparison. The run used one Colab T4. The encoder was not fine-tuned.

Reproduce that number with python evaluate.py --train-root data/train --test-root data/test --output-dir runs/official. Inference from the saved weights is python predict.py --cache-dir runs/official --image-root data/test. The dataset is the same 2,400 / 400 scene split as Assignments 1 and 2. The support list is supports/seed0.json: one file per class, drawn with numpy.random.default_rng(0) from the sorted file names. The other 2,384 training images are never opened. Test labels are used only to print accuracy.

2. Foundation model and one-shot recipe

SigLIP stays frozen. Each folder name is turned into a short phrase before any test image is scored. InsideCity is "city scene surrounded by buildings," OpenCountry is "open countryside," TallBuilding is "tall building," and the other folders are the obvious words, such as "kitchen" and "highway." Four templates wrap each phrase: "a photo of a {phrase}.", "a photo of the {phrase}.", "an image of a {phrase}.", and "a {phrase} scene." The four embeddings are averaged and L2-normalized. That vector is the submitted class weight. SigLIP's learned logit scale multiplies the cosine, which does not change the argmax and keeps the score in the model's units.

The one-shot branch uses the same embedding function on the 16 support photos. The photo and a horizontal flip are averaged, so the test-time augmentation matches training. Two extra classifiers are scored in the same forward pass. The photo-only classifier uses that visual vector. The equal-mix classifier uses the normalized sum of the text vector and the visual vector. Equal weight was fixed before the test pass. This assignment allows no second labeled image as a validation set, so there is no legal place to search a mixing coefficient.

The photo is a worse class vector than the name. One random scene, drawn by a seed rather than picked by hand, cannot cover the layouts inside a class, and the photo-only accuracy is 68.75%. Adding it to a text vector that already scores 85% pulls 12 correct test images onto the wrong side of the boundary. The mix scores 82%. The saved cache.pt therefore stores the text vectors. The 16 photos are still embedded, and both comparison accuracies are printed next to the official line, so the one-shot measurement is part of the reproduction rather than a hidden extra run.

The errors sit where the English name is ambiguous. Seven classes are perfect: Bedroom, Coast, Flower, Highway, Kitchen, LivingRoom, and Mountain. Office is 24/25, Store 23/25, and Street 24/25. Forest and Industrial are 21/25. The urban and open-layout classes are the rest of the loss: OpenCountry 15/25, Suburb 18/25, TallBuilding 17/25, and InsideCity 2/25. InsideCity is 23 of the 60 errors. The folder name is not a phrase the model already uses, and the paraphrase overlaps street, suburb, and tall-building scenes. A single InsideCity photograph does not repair that overlap, which is why trusting the photo more would not be a free fix. The flip helps small pose changes. It does not invent a boundary the text encoder never had.

3. Conclusion

With one label allowed per class, the foundation model's class name was more accurate than the labeled photograph. The training step that mattered was writing the 16 phrases, averaging four prompts, and flipping each image at test time. The equal-mix rule was the natural way to spend the one labeled photo, and it cost 3 points because that photo was a noisy prototype of a scene. SigLIP already recognizes bedrooms, coasts, and highways. Sixteen photographs do not re-teach it InsideCity. On one free T4, a frozen foundation model plus a prompt ensemble is the practical one-shot system. Training a classifier from those 16 samples would spend the only labels on a representation the text encoder already has.
